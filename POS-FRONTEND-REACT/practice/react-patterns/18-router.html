Lesson 18: useNavigate & useParams

Concept — Two router hooks your project uses: 
{`// useNavigate — go to a different page
const navigate = useNavigate();
navigate('/profile/brand');          // go to brand list
navigate('/profile/brand/edit/5');   // go to edit page with id=5
navigate(-1);                        // go back (like browser back button)

// useParams — read values from the URL
// Route defined as: /profile/brand/edit/:identifier
// URL in browser:   /profile/brand/edit/APPLE
const { identifier } = useParams();
console.log(identifier); // → "APPLE"

// Route: /profile/racks/edit/:id
// URL:   /profile/racks/edit/5
const { id } = useParams();
console.log(id); // → "5"`}
