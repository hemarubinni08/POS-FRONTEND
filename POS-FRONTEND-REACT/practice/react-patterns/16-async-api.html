Lesson 16: Async/Await & API Calls

Concept: API calls take time. async/await lets you wait for them without freezing the page. 
{`// Without async/await (confusing callbacks):
fetch('/api/brands').then(res => res.json()).then(data => setData(data));

// With async/await (reads like normal code):
const fetchData = async () => {
  setLoading(true);
  try {
    const response = await axiosInstance.post('/brand/list', { page: 0, sizePerPage: 10 });
    setData(response.data.dtoList);  // ← wait for response, then use it
    setTotalPages(response.data.totalPages);
  } catch (error) {
    setError(error.response?.data?.message || "Failed to load");
  } finally {
    setLoading(false);  // ← always runs, success or failure
  }
};

useEffect(() => {
  fetchData();  // call it when component loads
}, []);`}
