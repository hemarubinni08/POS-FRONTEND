Lesson 17: Reusable Components

Concept: Instead of copy-pasting the same form for Brand, Shelf, Model... your project uses ONE CommonAddTemplate that is configured via props. 
{`// WITHOUT reusable component — you'd repeat this for Brand, Shelf, Model, Category...
function BrandAdd() { /* form code */ }
function ShelfAdd() { /* same form code */ }
function ModelAdd() { /* same form code again */ }

// WITH reusable component — write once, use everywhere:
function BrandAdd() {
  const extraFields = [{ key: "status", type: "select", options: [...] }];
  return ;
}
function ShelfAdd() {
  const extraFields = [{ key: "status", type: "select", options: [...] }];
  return ;
}
// CommonAddTemplate handles ALL the form logic — just configure it with props`}
