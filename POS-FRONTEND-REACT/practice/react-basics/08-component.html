Lesson 08: What is a React Component?

Concept

A component is just a JavaScript function that returns HTML-like code (called JSX).

Every file in your project is a component: Login.jsx, BrandList.jsx, Header.jsx etc.

// This is a component:
function Greeting() {
  return <h2>Hello, World!</h2>;
}

// Use it like an HTML tag:
<Greeting />
