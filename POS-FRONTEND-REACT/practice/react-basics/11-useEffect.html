Lesson 11: useEffect

Concept: useEffect runs code AFTER the component renders. Used to:
  • Fetch data from API when page loads
  • Run code when a value changes
{`useEffect(() => {
  // code to run
}, [dependencies]);
//  ↑ empty [] = run ONCE when component loads
//  ↑ [value] = run whenever "value" changes
//  ↑ no [] = run after EVERY render (dangerous!)`}
From your project: 
{`// Profile.jsx — fetch user data when page loads:
useEffect(() => {
  fetchUserData(username);
}, []);  // ← [] means: run once on load

// ListTemplate.jsx — re-fetch when page or rowsPerPage changes:
useEffect(() => {
  fetchData(page);
}, [page, rowsPerPage]);  // ← runs when page or rowsPerPage changes`}
