Lesson 13: Conditional Rendering

Concept: Show or hide parts of the UI based on state. Three ways: 
{`// 1. && operator (show or nothing)
{isLoading && 
Loading...
}

// 2. Ternary (show this OR that)
{isLoading ? 
Loading...
 : 
Data here
}

// 3. if/return (return early from component)
if (loading) return 
Loading...
;`}
