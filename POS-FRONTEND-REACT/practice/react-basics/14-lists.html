Lesson 14: Lists & Keys

Concept: Use .map() to render an array of items as JSX. Each item needs a unique key prop so React can track them. 
{`// Array of data:
const brands = [
  { id: 1, identifier: "APPLE" },
  { id: 2, identifier: "SAMSUNG" },
];

// Render as list:
{brands.map((brand) => (
          ← key must be unique
    {brand.id}
    {brand.identifier}
  
))}`}
