Lesson 10: useState

Concept: useState lets a component REMEMBER a value between renders. When the value changes, React automatically re-renders the component to show the new value. 
{`const [value, setValue] = useState(initialValue);
//    ↑ read   ↑ update   ↑ starting value`}
From your project: 
{`const [username, setUsername] = useState('');    // Login.jsx
const [data, setData] = useState([]);           // ListTemplate.jsx
const [loading, setLoading] = useState(true);  // ListTemplate.jsx
const [page, setPage] = useState(0);           // ListTemplate.jsx`}
